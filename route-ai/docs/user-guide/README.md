# 📖 Operations & Dispatcher User Manual

Welcome to the RouteAI Operations Guide. This manual explains how dispatchers and fleet supervisors utilize the platform daily.

## Key Operations Tasks

### 1. Operations Dashboard Overview
- Monitor live fleet metrics: Total Active Drivers, Pending Deliveries, Completed Runs, On-Time SLA Rate.
- View real-time alert feed for vehicle breakdowns or delivery delays.

### 2. Dispatching & Route Optimization
1. Navigate to **Routes** page.
2. Select pending deliveries from the queue.
3. Select available drivers and vehicles.
4. Click **Optimize Route with AI**.
5. Inspect the generated route map and waypoint sequence, then click **Dispatch to Driver**.

### 3. Interacting with AI Assistant
1. Navigate to **AI Assistant** page or open the drawer widget.
2. Type natural language queries:
   - *"Which driver is closest to 5th Avenue with 200kg extra capacity?"*
   - *"What is our policy for cold-chain temperature violations?"*
