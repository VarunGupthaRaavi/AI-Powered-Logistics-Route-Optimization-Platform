# Contributing to RouteAI

Thank you for considering contributing to RouteAI! Enterprise logistics route optimization requires rigorous standards, code clarity, and robust security.

## Code of Conduct
Please maintain a respectful, professional environment for all contributors.

## Development Workflow
1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Follow PEP 8 guidelines for Python and ESLint/Prettier standards for JavaScript/React.
3. Ensure unit tests pass (`pytest` for backend, `npm test` for frontend).
4. Commit your changes with clear semantic messages (`feat: add dynamic rerouting algorithm`).
5. Open a Pull Request targeting the `main` branch.

## Directory Structure Overview
- `frontend/`: React + Vite + Tailwind CSS dashboard application.
- `backend/`: FastAPI + SQLAlchemy + Google Gemini AI engine.
- `docs/`: System architecture, API specs, and user guides.
- `docker/`: Development & deployment containers.
